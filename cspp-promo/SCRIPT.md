## إعادة الإنتاج
```bash
bash make_video.sh
```
يحتاج: ffmpeg، Node + Playwright (Chromium)، Python 3 + numpy.
- لتعديل أي نص على الشاشة: `build.py` (المشاهد) و `style.css` (التصميم).
- لقطات الخلفية السينمائية (Higgsfield – Kling 3.0 Turbo): مدينة خضراء، موقع إنشاء مبنى أخضر بمهندسين، برج مستدام تحت الإنشاء، تركيب ألواح شمسية، كرة أرضية بنبتة، أوراق شجر، يدين بنبتة — في `assets/broll/`.
- الموسيقى والمؤثرات أصلية ومولّدة بالكود (`audio_mix.py`) — بدون أي حقوق ملكية.
